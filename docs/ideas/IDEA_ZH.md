# 3DrawAgent 风格蒸馏与分对象动画

记录日期：2026-11-05

## 核心想法

**核心是蒸馏 3DrawAgent 的绘画风格，让小模型生成的 3D sketch 更容易被视觉模型识别，同时保持动画表达能力。**

- 当前痛点之一：需要与已有 baselines 比较 CLIP 分数。
- 出发点：据当前讨论，3DrawAgent 的 CLIP 表现不错，可以参考其首帧及 object 曲线的绘画风格。
- 待验证假设：这种风格能改善我们的图文对齐分数；收益不能仅凭对方的分数推断。
- 表达格式继续用 Three.js，并通过注释标记 stroke 的语义，不必照搬对方的输出格式。
- 风格蒸馏是核心；下面的工作流是可以分别测试的实现方案。

## 方案 A：分对象绘制与动画

1. 先生成 storyboard，确定 objects、初始形态、姿态、朝向及运动/交互。
2. 统一世界坐标、尺度和时间轴，以共享关键时间点和空间锚点约定同步与接触。
3. 按 storyboard 为每个 object 单独绘制静态 3D sketch，使用局部坐标、命名 THREE.Group 和语义注释。
4. 每对象可多次 rollout，通过多视角视觉比较选择首帧候选。
5. 将实际几何中的部件和接触点绑定到共享锚点，再分别生成对象的运动脚本。
6. 组合到同一场景渲染，检查比例、同步、接触以及刚体结构保持。

必要约定：统一坐标轴、尺度和时间；明确对象局部坐标到场景坐标的关系。
交互锚点应让相关对象引用同一位置和时刻，避免各自独立解释。

## 方案 B：简化版

1. 用参考 3DrawAgent 的风格，一次绘制包含全部 objects 的首帧。
2. 在这个首帧上生成整体 Three.js 动画，沿用现有流程。

先用此方案验证风格本身的收益，再判断是否值得引入分对象工作流。

## 最小验证

- [ ] 选相同 tasks，对比当前风格与参考 3DrawAgent 的风格。
- [ ] 固定渲染设置与采样预算，对比 CLIP 分数和人工视觉判断。
- [ ] 分开观察首帧可识别性、动画语义和跨对象交互，避免只提升静态分数。
- [ ] 若风格收益成立，再比较整体生成与分对象生成，记录额外成本。
- [ ] 用筛选后的教师轨迹训练学生，验证风格收益能否迁移到小模型。
